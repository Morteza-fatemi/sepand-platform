## Public engineering focus
- Multi-role authorization in an education/transport context.
- Parent/student/driver workflows and service requests.
- Safe, explainable attendance and route state transitions.
- Location updates and eventual consistency for live maps.
- Identity/rate-limiting and payment-failure recovery.
- Data quality and school reference-data reconciliation.

## Data-handling limits
No student data, GPS coordinates, school identifiers, real transport routes, contract values, security endpoints, credentials or private incident logs are published here. All displayed values in the demonstration are invented.
